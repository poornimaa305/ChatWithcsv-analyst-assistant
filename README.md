# CSV Analytics Assistant

An interactive data analytics web application built using Python, Pandas, and Streamlit.

## Features

* Upload and analyze CSV datasets
* Dataset preview and exploration
* Summary statistics
* Missing value analysis
* Correlation matrix
* Interactive charts (Bar, Line, Histogram)
* Natural language-style analytics queries
* Dataset download functionality

## Technologies Used

* Python
* Pandas
* Streamlit
* Matplotlib

## Example Questions

* How many rows?
* Highest total revenue
* Average unit price
* Total net revenue
* Show missing values
